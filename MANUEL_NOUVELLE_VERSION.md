## Avant de commencer 📌

### La Migration de Vos Données

#### Que Va-t-il Se Passer ?

1. **Vos données actuelles** seront **automatiquement transférées** vers la nouvelle version
2. **Aucune perte de données** : tout est préservé (clients, véhicules, documents, historiques)
3. **L'ancienne version restera accessible** pendant une période de transition
4. **Support dédié** pour vous accompagner

#### Ce Que Vous Devez Faire

**Rien !** La migration technique est entièrement prise en charge. Vous devrez simplement :

1. Noter vos nouveaux identifiants de connexion (envoyés par email)
2. Vous connecter à la nouvelle version
3. Vérifier que toutes vos données sont bien présentes
4. Commencer à utiliser la nouvelle interface

#### Calendrier de Migration

- **Phase 1 - Préparation** : Export et vérification de vos données
- **Phase 2 - Migration** : Transfert automatique vers la nouvelle version
- **Phase 3 - Validation** : Vérification et tests avec votre équipe
- **Phase 4 - Bascule** : Mise en service de la nouvelle version
- **Phase 5 - Accompagnement** : Support renforcé pendant 1 mois

> 💡 **Conseil** : Profitez de la période de transition pour former progressivement votre équipe sur la nouvelle interface.

`Documents → Onglet "Devis" → "+ Nouveau devis"`

#### Changements notables

✨ **Nouveau** :
- **Import depuis rapport d'expertise** : L'IA extrait automatiquement les réparations et pièces

- **Envoi par email intégré** : Directement depuis l'application
- **Aperçu PDF instantané** : Voir le rendu avant envoi

📍 **Même emplacement** :
- Sélection client et véhicule
- Liste des réparations et pièces
- Prix unitaires, quantités, remises
- Total HT et TTC

#### Processus Simplifié

##### Création d'un Devis

**Étape 1** : `Documents → Devis → + Nouveau devis`
**Étape 2** : Sélectionner client et véhicule
**Étape 3** : (Optionnel) Importer depuis un rapport d'expertise
**Étape 4** : Ajouter/modifier réparations et pièces
**Étape 5** : Vérifier les calculs automatiques
**Étape 6** : Enregistrer et/ou envoyer par email

##### Conversion en Ordre de Réparation

**Ancien processus** : Recréer manuellement l'ordre
**Nouveau processus** : `Devis validé → Bouton "Convertir en ordre" → ✅ Terminé`

**Ancien processus** : Recréer la facture
**Nouveau processus** : `Ordre terminé → Bouton "Facturer" → Ajustements → Générer`

**Accès** : `Ctrl+K` (ou `Cmd+K` sur Mac) ou icône 🔍 en haut

- **Clients** : Par nom, prénom, email, téléphone

1. Appuyer sur `Ctrl+K`
2. Taper votre recherche (ex: "Dupont", "AA-123-BB", "DEV-2024-")
3. Sélectionner le résultat dans la liste
4. Accéder directement à la fiche

> 💡 **Astuce** : La recherche est intelligente et tolère les fautes de frappe !

## FAQ et Support 💬

### Questions Fréquentes

#### Général

**Q : Mes données sont-elles toujours accessibles dans l'ancienne version ?**
R : Oui, l'ancienne version reste accessible pendant **30 jours** après la migration pour consultation. Passé ce délai, seule la nouvelle version sera disponible.

**Q : Puis-je revenir à l'ancienne version si je ne suis pas satisfait ?**
R : Pendant la **période de transition de 30 jours**, un retour en arrière est possible. Au-delà, seule la nouvelle version sera maintenue.

**Q : Est-ce que toute mon équipe doit utiliser la nouvelle version ?**
R : Oui, une fois la migration effectuée, tous les utilisateurs doivent basculer sur la nouvelle version pour garantir la cohérence des données.

---

#### Connexion et Accès

**Q : J'ai perdu mon mot de passe, comment le réinitialiser ?**
R : Sur la page de connexion, cliquez sur "Mot de passe oublié ?". Vous recevrez un email avec un lien de réinitialisation.

**Q : Puis-je utiliser mon ancien mot de passe ?**
R : Non, pour des raisons de sécurité, vous devez créer un nouveau mot de passe lors de votre première connexion.

**Q : Combien d'utilisateurs peuvent se connecter en même temps ?**
R : Tous les utilisateurs de votre abonnement peuvent se connecter simultanément, sans limite.

---

#### Données et Migration

**Q : Toutes mes données ont-elles été transférées ?**
R : Oui, **100% de vos données** sont migrées : clients, véhicules, documents, factures, encaissements, historiques. Une vérification est effectuée avant la bascule.

**Q : Les documents PDF de l'ancienne version sont-ils accessibles ?**
R : Oui, tous vos PDF historiques sont conservés et accessibles dans la nouvelle version.

**Q : Mes photos de véhicules sont-elles transférées ?**
R : Oui, toutes les photos et documents attachés sont migrés avec les véhicules correspondants.

**Q : Puis-je importer des données depuis Excel ?**
R : Oui, la nouvelle version permet l'import de clients et véhicules depuis fichiers CSV/Excel. Contactez le support pour assistance.

---

#### Fonctionnalités

**Q : Comment activer l'Assistant IA ?**
R : Allez dans `Paramètres → Relance IA` et activez les fonctionnalités souhaitées. Un guide détaillé est disponible dans l'interface.

**Q : Les relances automatiques remplacent-elles mes relances manuelles ?**
R : Non, elles sont **complémentaires**. Vous pouvez toujours envoyer des relances manuelles. L'IA se charge des relances systématiques selon vos paramètres.

**Q : Puis-je personnaliser les templates de documents PDF ?**

### Problèmes Courants et Solutions

#### "Je ne retrouve pas un client/véhicule"

**Solution 2** : Vérifier les filtres actifs dans la liste
**Solution 3** : Si toujours absent, contacter le support avec le nom exact

#### "La page est lente à charger"

**Solution 1** : Vider le cache du navigateur (Ctrl+Shift+Suppr)
**Solution 2** : Vérifier votre connexion internet
**Solution 3** : Essayer un autre navigateur (Chrome recommandé)
**Solution 4** : Fermer les autres onglets et applications

#### "Je n'arrive pas à uploader une photo"

**Solution 1** : Vérifier la taille du fichier (max 10 Mo)
**Solution 2** : Vérifier le format (JPG, PNG, PDF uniquement)
**Solution 3** : Essayer de réduire la résolution de l'image
**Solution 4** : Désactiver temporairement les extensions de navigateur

#### "Le PDF ne se génère pas"

**Solution 1** : Vérifier que tous les champs obligatoires sont remplis
**Solution 2** : Attendre quelques secondes et réessayer
**Solution 3** : Rafraîchir la page (F5) et réessayer
**Solution 4** : Si le problème persiste, contacter le support

#### "Je ne reçois pas les notifications par email"

**Solution 1** : Vérifier les paramètres de notifications (`Paramètres → Notifications`)
**Solution 2** : Vérifier le dossier spam/indésirables
**Solution 3** : Ajouter l'adresse d'envoi à vos contacts
**Solution 4** : Vérifier que votre adresse email est correcte dans votre profil
